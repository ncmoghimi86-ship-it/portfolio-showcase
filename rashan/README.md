# 🌐 Rashan — Corporate Website & Client Platform

**Corporate website with admin panel, ticketing, and AI chatbot**

🔗 **Live Demo:** [https://rashanit.ir/](https://rashanit.ir/)

---

## 📌 Overview

Corporate website and client portal for **Rashan IT** — a company specializing in IT services, networking, and security solutions.

Designed and developed from scratch as a solo project.

---

## ✨ Key Features

### 🎨 Public Website
- Company introduction and services
- Portfolio and case studies
- Contact forms
- Full SEO optimization
- Fully responsive (mobile-first)

### 🛠️ Admin Panel
- Content management for all pages
- Full CRUD operations
- User and role management

### 🎫 Ticketing System
- Client support tickets
- Status tracking
- Email notifications

### 🤖 AI Chatbot
- Smart assistant built with **n8n**
- Automated responses
- Lead capture

---

## 🛠️ Tech Stack

**Frontend + Backend:**
- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS

**Database:**
- Prisma ORM
- MySQL

**Automation:**
- n8n (chatbot workflows)

**SEO:**
- Full meta tags optimization
- Sitemap generation
- Open Graph support
